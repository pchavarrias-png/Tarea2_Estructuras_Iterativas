
# Tarea 2 - Estructuras Iterativas en Python

## Descripción del proyecto

Este proyecto corresponde a la Tarea 2 del curso Principios de Programación 1 de la Universidad CENFOTEC.

Consiste en el desarrollo de cuatro programas en Python mediante estructuras iterativas, condicionales, contadores, acumuladores y validación de datos.

## Objetivos

- Aplicar las estructuras iterativas while y for.
- Implementar estructuras condicionales.
- Utilizar contadores y acumuladores.
- Validar los datos ingresados por el usuario.
- Comprobar el funcionamiento mediante casos de prueba.
- Utilizar Git y GitHub para el control de versiones.

## Ejercicios desarrollados

### Ejercicio 1: Control de temperatura
Simula el incremento de temperatura hasta alcanzar o superar una temperatura objetivo.

### Ejercicio 2: Consumo semanal de agua
Registra el consumo de agua durante siete días y calcula el total, promedio, consumo máximo y días con consumo superior a 150 litros.

### Ejercicio 3: Gestión de estacionamiento
Administra las entradas y salidas de vehículos, los espacios disponibles y los ingresos generados.

### Ejercicio 4: Gestión de recursos de una expedición
Controla el consumo diario de agua y alimentos, valida los recursos disponibles y genera un informe final.

## Requisitos de ejecución

- Python 3.
- Visual Studio Code o cualquier editor compatible con Python.
- No se requieren bibliotecas externas.

## Instrucciones de ejecución

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Seleccionar el archivo Python que se desea ejecutar.
4. Ejecutar el programa.
5. Ingresar los datos solicitados en la terminal.
